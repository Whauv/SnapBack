What the product does

Built around the exact moment a student loses context.

SnapBack is not a generic transcript recorder. It is optimized for the return moment: what changed, what mattered, and what the student needs to know right now.

Signal

Context-aware recap

The product summarizes only the missed slice of the lecture instead of forcing students to scan a full transcript.

Focus

Important moments surfaced

Topic shifts, academic keywords, and high-signal professor phrases are elevated so the student can recover the thread quickly.

Retention

Session to study workflow

A live lecture can become exportable notes, review priorities, flashcards, and quiz questions without leaving the session.

Getting started

Install paths for builders, testers, and reviewers.

Right now the product is best explored through the local app and the Github repository. The landing page makes both easy to reach.

01

Clone the repo

Start with the GitHub repository to inspect the architecture, backend services, Chrome extension flow, and the current Phase 8 direction.

02

Run the backend

Create the Python environment, install the API requirements, configure `.env`, and start the FastAPI server that powers sessions, recaps, exports, and study packs.

03

Open the product

Launch the current SnapBack interface from the product app to explore the live session controls, recap flow, transcript drawer, settings, and exports.

Where it works

Current product surfaces

— Zoom-style React panel for the main product experience.

— Google Meet Chrome extension with floating entry point and side panel flow.

— Shared host-adapter architecture already prepared for deeper platform integrations.

Privacy posture

Designed to support both convenience and control.

Students can use cloud transcription for convenience or switch to local whisper.cpp processing for stronger privacy.

Session cleanup, consent flow, export controls, and configurable backend retention are already part of the current product.
